# 履约与商业体验诊断与调查方案

> 本文是「海外代购业绩提升」专题的第二篇。
> 第一篇给出了「目标系统长什么样」的候选方案池，但**先做什么、后做什么需要数据支撑**，不能仅凭主观判断。本文就是这套「先诊断、后排期」的调查方案。

---

## 一、为什么必须先调查，而不是先动手

这些维度（履约、价格、丰富度……）的特点是：
- **计算上没难度**：履约率、价差率、缺货率等指标，SQL 即可统计。
- **判断上有难度**：履约率 80% 算差吗？送到用户手上 7 天算慢吗？没有基准就无法决策。
- **资源有限**：不可能所有维度一起优化，必须按业务价值排序。
- **现状不清**：当前到底哪个维度差、差到什么程度、影响多少 GMV，缺乏数据支撑，仅有定性判断。

> **结论：发起一次基于系统数据 + 用户行为的诊断调查，拿到每个维度的真实分布，然后决定改不改、改哪个。这件事的优先级排在所有改造之前，是决策前提。**

---

## 二、海外代购的完整维度体系

### 2.1 三层漏斗结构

```
履约层（能不能把货准时、完好地送到用户手上）
   └─ 决定用户「敢不敢下单」——信任问题
商业体验层（价格、速度、丰富度、质量、售后）
   └─ 决定用户「愿不愿下单」——选择问题
数据/搜索层（第一篇已展开）
   └─ 决定用户「找不找得到、配不配得准」——入口问题
```

三层是漏斗关系：搜索找不到 → 体验层比价 → 履约层成交复购。任何一层漏了，前面做得再好都白搭。

### 2.2 核心指标体系

> 本次调查聚焦 **4 大维度 12 个核心指标**，选取标准是：数据现成（系统已有）、能直接统计、能驱动决策。其余指标（如 NPS、原厂溯源率、物流可视化等）作为备选，首轮调查暂不涵盖。

| 维度 | 子维度 | 量化指标 | 数据来源 |
|---|---|---|---|
| **A. 履约确定性** | A1 订单履约率 | 已发货订单 / 总订单 | 订单系统 |
| | A2 缺货失单率 | 因缺货未成交 / 下单尝试 | 订单 + 库存 |
| | A3 库存准确率 | 系统库存与上游实际一致比例 | 对账数据 |
| **B. 价格与时效** | B1 价差率 | (我司售价 - 上游官网价) / 上游官网价 | 比价脚本 |
| | B2 价格新鲜度 | 价格更新 <24h 的 SKU 占比 | 索引时间戳 |
| | B3 平均交付周期 | 下单→签收天数（含跨境+清关） | 物流系统 |
| **C. 商品全面性** | C1 型号覆盖率 | 我司可售型号数 / 主流竞品型号数 | 竞品比对 |
| | C2 搜索命中率 | 用户搜索有结果占比 | 搜索日志 |
| | C3 资料完整度 | 有参数+图片+规格书的 SKU 占比 | 商品字段 |
| **D. 客户留存** | D1 复购率 | 90 天内二次下单用户占比 | 订单 |
| | D2 客单价 | 平均订单金额 | 订单 |
| | D3 退换货率 | 退换货 / 成交 | 售后系统 |

### 2.3 关于「阈值」的处理原则

> **本次调查先不预设具体阈值，只看真实数据分布。**

原因：
1. **避免先入为主**：预设阈值会影响统计口径的选取，有导向性风险。
2. **避免对标误判**：行业基准不一定适用我司业务结构，盲目对标可能误导决策。
3. **数据先行的纪律**：先看真实分布（均值、中位数、分位数、分布形态），再基于分布特征和业务判断，给出「红灯/绿灯」阈值。

**调查输出形式**：每个指标给出**统计分布图 + 关键分位数**，例如：
- 履约率：整体均值 X%，按供应商分组的箱线图，按月份的趋势线。
- 交付周期：直方图 + P50 / P90 / P99 分位数。
- 价差率：分布直方图，标出正负偏离的占比。

拿到分布后再回答两个问题：
- **什么样算问题**：分布中明显偏离主峰的尾部（例如 P90 之外），或与业务常识严重不符的区间。
- **什么样算正常**：分布的主峰区间，或业务上可接受的区间。

阈值的具体数值，由调查结论 + 业务部门共同确认，不预设。

## 三、海外代购特殊性的调查纳入原则

海外代购相比国内代购 / 自营，有几个特有的影响因素。**是否纳入本次调查，取决于它们对业绩的影响程度**——这本身也是调查要回答的问题。

### 3.1 可能影响业绩的海外特有因素

| 因素 | 可能的影响 | 是否纳入首轮调查 |
|---|---|---|
| 报关时效 | 直接影响 B3 交付周期，报关卡住是代购履约的主要不确定项 | ✅ 纳入（已包含在 B3 中，需单独统计报关段耗时） |
| 跨境物流模式（空运/海运/快递） | 影响成本和时效的权衡 | ✅ 纳入（B3 按物流模式分组统计） |
| 汇率波动 | 影响定价稳定性和利润空间 | ⚠️ 待定（先观察价差率分布是否存在异常，若存在异常再进行深入分析） |
| 上游供应商发货速度 | 代购特有段的核心瓶颈 | ✅ 纳入（B3 按供应商分组统计） |
| 库存数据新鲜度 | 海外供应商 API 频次受限，库存数据更新慢 | ✅ 纳入（A3 + B2） |

### 3.2 暂不纳入的因素

以下因素虽然存在，但首轮调查先不考虑，避免范围膨胀：
- 跨国合规认证（CE / FCC / RoHS）：属于商品资料范畴，归入 C3 资料完整度。
- 跨境支付和结算周期：属于财务侧，不影响用户侧体验。
- 关税税率结构：属于定价策略，归入 B1 价差率分析。

> **原则**：首轮调查聚焦「直接影响用户下单决策和履约体验」的因素，间接因素等首轮出结论后再按需深挖。

## 四、调查方案

### 4.1 调查目标

**用 4 周时间，把上述 4 大维度 12 个指标的真实数据分布算清楚，输出一份「维度优化优先级排序」决策文档。**

### 4.2 调查范围与方法

| 调查类型 | 覆盖内容 | 方法 |
|---|---|---|
| **A. 系统数据统计**（主） | A~D 全部量化指标 | 历史订单/库存/物流/售后数据跑批统计 |
| **B. 竞品横向对比** | B1 价差、C1 覆盖率、C2 命中率 | 抽样热门型号，对照 digikey/mouser/云汉 |
| **C. 用户行为分析** | C2 命中率、搜索转化漏斗 | 搜索日志、���击日志、加购日志、下单日志 |

A 和 C 占主要工作量，因为它们是可量化、可归因、可决策的主干。B 用于给价差和覆盖率找外部参照。

### 4.3 抽样设计

1. **时间窗**：最近 6 个月数据，覆盖工作日 / 周末、促销日 / 平日，避免单月偏差。
2. **型号分层抽样**：按热度分 4 档（Top 1k / 1w-10w / 10w-100w / 100w+），每档等比抽样，避免只看到头部型号。
3. **供应商分层**：26 家供应商单独统计，识别履约表现明显偏离整体的供应商——可能少数几家供应商贡献了大部分履约问题。
4. **用户分层**：B 端大客户 / 中小企业 / 个人工程师分开统计，三者对价格、交期、质量的容忍度差异极大。

### 4.4 数据源清单

```
订单系统      → A1, A2, D1, D2, D3
库存系统      → A2, A3, B2
价格系统      → B1, B2
物流/清关系统 → B3（需拆出报关段、跨境段、国内段）
商品主数据    → C1, C3
搜索日志      → C2
上游 API/爬虫 → A3（库存准确性回查）, B1（外部比价）
```

> **前置条件**：调查启动前需先完成数据访问权限和数据字典的对齐，避免因数据源协调问题影响进度。

### 4.5 归因分析（让数据能驱动行动）

单一指标数值无法直接驱动行动，必须拆解到根因。以履约率为例：

```
履约失败
├─ 上游缺货
│   ├─ 库存数据过期        → 数据新鲜度问题 → 对应方向 A（数据中台）
│   ├─ 上游超卖            → 多家卖同一批次 → 对应方向 A + 供应商分级
│   └─ 型号映射错误        → MPN 归一化问题 → 对应方向 A
├─ 报关延误                → 履约链路问题   → 对应方向 C（履约优化）
└─ 我方采购失败            → 流程/资金问题  → 业务流程优化
```

每个叶子节点对应一个明确的改进行动，并映射回第一篇的候选方向（A/B/C/D/E）。调查的真正价值在这一步——**把指标拆成可行动的归因树**。

其他维度同样需要拆解到根因，例如：
- 价差大 → 是定价策略问题，还是汇率 / 关税核算问题？
- 交付慢 → 是供应商发货慢、跨境物流慢，还是报关慢？需按物流链路分段定位。
- 资料缺 → 是型号映射不上，还是上游本身就没有资料？

### 4.6 GMV 损失量化（让优先级排得出来）

对每个存在问题的维度，估算「改进到合理水平后能挽回的 GMV」：

```
维度 X 的 GMV 损失 = 当前订单数 × (改进后转化率 - 当前转化率) × 客单价
                  或
                  = 失单量 × 客单价 × 复购系数
```

示例（假设性数字，仅作说明）：
- 缺货失单率当前 8%，合理水平假设 3%，差额 5% 失单。
- 月订单 10w 单，5% = 5000 单失单。
- 客单价 ¥800，5000 × 800 = ¥400w/月潜在 GMV 损失。
- 若改进数据新鲜度能把失单率从 8% 降到 5%，可挽回 ¥240w/月。
- 该数字即为对应改造方向（如数据中台）的 ROI 测算依据。

> **关键产出**：每个有问题的维度都算出一条 GMV 损失数字，最终所有改进项按「GMV 挽回 / 改造成本」排序，即为优先级。

## 五、决策矩阵（调查输出模板）

调查完成后，输出决策矩阵：

| 维度 | 当前分布 | 主要问题 | 根因 | GMV 损失/月 | 对应改造方向 | 改造成本 | ROI | 优先级 |
|---|---|---|---|---|---|---|---|---|
| A2 缺货失单率 | 均值 8%，P90 15% | 尾部严重 | 库存数据过期 | ¥240w | 方向 A | 中 | ⭐⭐⭐⭐⭐ | P0 |
| A1 履约率 | 均值 80% | 整体偏低 | 清关+上游超卖 | ¥180w | 方向 C + A | 高 | ⭐⭐⭐⭐ | P0 |
| B3 平均交付 | P50 14 天 | 整体偏慢 | 跨境物流模式 | ¥150w | 方向 C | 高 | ⭐⭐⭐ | P1 |
| C3 资料完整度 | 均值 45% | 整体偏低 | 无自动增强 | ¥90w | 方向 A | 低 | ⭐⭐⭐⭐⭐ | P0 |
| B1 价差率 | 均值 +12% | 整体偏高 | 定价策略 | ¥300w | 业务策略 | 低 | ⭐⭐⭐⭐⭐ | P0 |
| ... | | | | | | | | |

> 上表的数字均为示例，实际数值由调查产出。

**判定规则**：
- **高 ROI** → 列为 P0，立即立项。
- **低 ROI** → 列为 P1/P2，寻找低成本方案或分期推进。
- **分布正常** → 维持监控，定期复测，暂不投入。

决策矩阵是「要不要改、先改哪个」的最终依据，也是第一篇候选方向池的优先级校准依据。

## 六、调查计划与交付物

### 6.1 时间安排（4 周）

| 阶段 | 时间 | 核心工作 | 阶段产出 |
|---|---|---|---|
| **准备期** | W1 | 指标口径确认、数据源对接、抽样设计定稿 | 《指标口径说明书》《数据源清单》《抽样方案》 |
| **采集期** | W2 | 系统数据跑批、竞品比价、用户行为日志分析 | 原始数据集 + 清洗后的分析数据集 |
| **分析期** | W3 | 归因树拆解、GMV 损失量化、分布分析、阈值初判 | 各指标分布报告 + 归因树 + GMV 损失测算表 |
| **结论期** | W4 | 决策矩阵成稿、优先级评审、候选方向校准 | **《海外代购业绩诊断报告》（本次调查的最终交付物）** |

### 6.2 最终交付物

调查结束时，输出一份完整的 **《海外代购业绩诊断报告》**，包含：

1. **各指标的真实数据分布**（直方图、箱线图、关键分位数）。
2. **每个指标的判定结论**：正常 / 存在问题 / 严重问题（基于分布特征 + 业务判断，不预设阈值）。
3. **归因树**：每个有问题的指标，拆解到可行动的根因层。
4. **GMV 损失测算**：每个有问题的维度，量化对应的潜在 GMV 损失。
5. **决策矩阵**：按 GMV 挽回 / 改造成本排序的优先级清单。
6. **第一篇候选方向的优先级校准建议**：方向 A/B/C/D/E 中，哪些是 P0、哪些延后。

### 6.3 中间产出（用于过程同步）

为保证调查不偏离方向，W2 结束和 W3 结束各设一次中间同步：
- **W2 末**：数据采集完成度同步（哪些指标数据齐了、哪些缺、缺的怎么降级）。
- **W3 末**：初步结论预沟通（分布分析出来的关键发现，避免 W4 才发现问题方向不对）。

## 七、调查的边界与约束

为保证调查能在 4 周内出结论，明确以下边界：

1. **时间窗**：基于最近 6 个月历史数据，不做更长时间回溯。
2. **抽样范围**：型号分层抽样（非全量），抽样方案在 W1 定稿后不再变更。
3. **竞品对照**：仅对照 digikey / mouser / 云汉三家，不全量覆盖所有竞品。
4. **用户调研**：首轮不纳入定性调研（电话访谈、问卷），仅基于系统数据和行为日志。若数据答不出"为什么"，再启动定性补充。
5. **指标范围**：聚焦 4 大维度 12 核心指标，其余次要指标（NPS、原厂溯源率等）本轮调查暂不涵盖。
6. **结论形式**：本次调查输出的是 **现状诊断 + 优先级建议**，不直接输出改造方案。改造方案依优先级立项后各自独立设计。

---

## 八、调查结论的后续应用

调查报告通过评审后，按以下路径推进：

1. **方向校准**：依决策矩阵，对第一篇的候选方向 A/B/C/D/E 重新排优先级，明确哪些进入首轮立项（P0）、哪些延后（P1/P2）。
2. **立项设计**：每个 P0 方向进入独立方案设计阶段，依第一篇第九节列出的配套文档清单拆出模块方案。
3. **指标常态化**：本次调查的 12 个指标纳入常态化看板，作为后续改造效果的复盘基线，定期复测。
