# 09-业务项目 — 业务代码与个人项目文档

记录工作中业务项目的设计与代码、个人 side project 的开发文档。

## 组织方式

**按项目名建子目录**，不预设通用分类。每个项目一个独立目录，例如：

- `09-业务项目/blog/` — 个人博客项目
- `09-业务项目/xxx-system/` — 某业务系统

## 项目子目录内建议结构

- 设计文档、架构图、数据模型放项目目录根下
- 踩坑、复盘可单独成文，front-matter 标注 `project: {项目名}`
- 可运行代码片段如需沉淀，按语言归 `01-java/`、`04-python/`，或源码分析归 `10-源码阅读/`

> 业务代码片段本身仍按语言归 `01-java/` / `04-python/`；本目录聚焦**项目级文档、设计、复盘**。
