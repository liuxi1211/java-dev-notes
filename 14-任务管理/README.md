# 任务管理使用说明

## 目录结构

```
14-任务管理/
├── 仪表盘.md              ← 每日入口，全局聚合展示
├── 2026-08月任务.md       ← 按月记录任务
├── 2026-09月任务.md
└── ...
```

## 日常使用流程

1. **早上**：打开 `仪表盘.md`，看今日待办和已过期
2. **新增任务**：在当月任务文件里添加，用 `Ctrl+P` → `Tasks: Create or edit task`
3. **完成任务**：直接在仪表盘点勾选，或在源文件里打勾
4. **临时想法**：先记在仪表盘的"任务速记区"，有空再整理

## 任务元数据说明

| 符号 | 含义 | 示例 |
|---|---|---|
| `📅` | 截止日期 | `📅 2026-08-18` |
| `🛫` | 开始日期 | `🛫 2026-08-15` |
| `🏁` | 完成日期（自动） | 打勾时自动添加 |
| `🔼` | 高优先级 | `🔼` |
| `🔺` | 中优先级 | `🔺` |
| `🔽` | 低优先级 | `🔽` |
| `🔁` | 循环 | `🔁 every day` |
| `#标签` | 分类标签 | `#工作/项目A` |

## 常用快捷键（建议手动设置）

在 设置 → 快捷键 中搜索 "Tasks"，推荐设置：

| 操作 | 推荐快捷键 |
|---|---|
| Tasks: Create or edit task | `Ctrl+T` |
| Tasks: Toggle done | `Ctrl+D` |
| Tasks: Postpone | `Ctrl+→` |

## 新建月份

每月初新建一个 `YYYY-MM月任务.md` 文件，结构参考当月文件。仪表盘的「本月任务文件」链接记得更新。
