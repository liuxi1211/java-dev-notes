# 自研CLI接入Agent实践

> 自研 CLI 工具（100+ 命令）如何让 Agent 好用：薄 Skill 分层披露 + AI 友好的 CLI 设计 + Skill 分发方案。相关笔记：[MCP-CLI-Skill三种接入模式对比](MCP-CLI-Skill三种接入模式对比.md)

## 1. 100+ 命令怎么办：分层披露

**核心原则：文档只教"入口+地图+坑"，参数细节交给 --help 自探索。**

### Skill 三层结构

1. **入口描述**（~100 token 常驻）：何时使用、认证方式、入口命令
2. **命令地图**（按需加载）：按分组一行一个，~50 行覆盖 100+ 命令，消除盲目探索
3. **自探索**（不写）：AI 现场 `--help` 查参数

```markdown
# mytool Skill
何时使用：用户提到 XXX / 处理 YYY 时使用 mytool
认证：运行 mytool auth login（首次）
入口：先跑 mytool --help 查看命令分组

## 命令分组
- 项目管理：mytool project create/list/delete
- 任务操作：mytool task add/list/assign
- 报表：mytool report daily/export
```

### 决策线：什么写进 skill，什么不写

| 情况 | 是否写进 skill |
|---|---|
| 参数名/类型（schema 能表达） | ❌ help 里有 |
| 反直觉操作（必须先 login） | ✅ |
| 多步流程有坑（create 后必须 config） | ✅ |
| 破坏性命令 | ✅ 标警示 |
| 命令隐式依赖/顺序要求 | ✅ |

**法则：skill 只写 schema 表达不了的——流程、坑、禁忌、何时用/何时不该用。**

## 2. CLI 本身要"对 AI 友好"（设计比文档重要）

| 要点 | 做法 |
|---|---|
| 分组 | namespace：`mytool project ...` / `mytool task ...` |
| help 全覆盖 | 每个子命令有 help、参数说明、示例（Cobra/Oclif 天然支持） |
| 稳定语义 | exit code、三流分离、`--json` 输出选项 |
| 错误可自纠错 | 报错要说"缺少 --group-id，运行 mytool group list 查看"——报错本身引导 AI 纠错 |
| 安全 | 幂等、`--dry-run` 让 AI 敢试 |

100 个命令不可怕，可怕的是没有分组和 help 的"平铺式" CLI。

## 3. Skill 分发的 4 种方式

| 维度 | ① npm postinstall | ② 安装脚本/npx | ③ 平台插件市场 | ④ 手动拷贝 |
|---|---|---|---|---|
| 用户步骤 | 1 条命令 | 1 条命令 | 1 次点击 | 多步 |
| 版本管理 | ✅ 随包升级同步 | ⚠️ 重跑脚本 | ✅ 平台管理 | ❌ 手动易过期 |
| 可发现性 | ⚠️ 靠文档传播 | ⚠️ 同左 | ✅ 市场可搜索 | ❌ 口口相传 |
| 安全审核 | npm 注册审核 | ⚠️ curl\|sh 争议 | ✅ 最规范 | 用户自担 |
| 离线/内网 | 需内网源 | 需镜像 | 需私有市场 | ✅ 最适合 |
| 提供方成本 | 低 | 低 | 高（审核周期） | 零 |
| 平台锁定 | 无 | 无 | ❌ 锁定单一平台 | 无 |

### 各方式适合场景

- **① npm/pip 内置**：已有包管理器分发渠道的工具；注意静默写用户目录有"越权"感，需适配多家客户端目录
- **② 安装脚本**：二进制分发（Go/Rust 产物）、企业内部工具链；最灵活但 curl|sh 有安全原罪
- **③ 插件市场**：面向大众的正式产品；体验最佳但锁定单一平台
- **④ 手动拷贝**：官方示例仓库、企业内部沉淀、离线环境唯一可行

### 选型决策树

```
分发给谁？
 ├── 大众用户 → ③ 插件市场 + ① 包管理器兜底
 ├── 开发者   → ① npm/pip 内置
 ├── 内网企业 → ② 内部脚本 或 ④ 内部 git 仓库
 └── 开源分享 → ④ git 仓库（社区会用 ①② 再包一层）
```

成熟项目 ①+②+④ 同时提供，有余力再做 ③。skill 本质是文件，多渠道分发边际成本极低——这是相比 MCP Server（必须运行进程、逐平台配置）在分发上的巨大优势。

### 给自研工具的最佳实践

```bash
# 用户只需一条命令
npm i -g mytool
# postinstall 自动执行：
#   1. 检测 ~/.claude/skills/、.trae/ 等目录
#   2. 写入 skill 文档
#   3. 打印 "skill 已安装，对 Agent 说 '用 mytool ...' 即可"
```

**用户永远不应该需要手动"下载 skill 再配置"两步走。**
