# 03-ai — AI 工程

大模型应用、Agent、RAG、Prompt、训推工程相关笔记。

## 子目录（按需使用）

- `llm/` — 大模型基础、能力边界、模型对比、上下文工程
- `prompt/` — Prompt 工程、Few-shot、CoT、模板库
- `agent/` — Agent 设计、工具调用、规划、多 Agent 协作
- `rag/` — RAG 架构、切片、检索质量、引用溯源
- `推理/` — 推理优化：vLLM、量化、KV Cache、部署

> 其他主题（微调、评测、LangChain/Dify 等框架）**直接放本目录根下**，数量多了再单独开子目录。
